# GooseGame

Две игры про гуся в браузере, обе под джойстик Xbox 360:

- **Гусь: Га-Га-Га** (`index.html`) — 2D, тыришь вещи у садовника
- **Гусь против зомби** (`shooter/index.html`) — 3D шутер от третьего лица, защищаешь гнездо от волн зомби

## Гусь против зомби (3D)

Открой `shooter/index.html`. three.js лежит в репе (`shooter/vendor`), интернет не нужен.

| Действие | Xbox 360 | Клава + мышь |
|---|---|---|
| Ходить | Левый стик | WASD |
| Камера | Правый стик | Мышь (кликни по игре, чтобы захватить курсор) |
| Стрелять | RT | ЛКМ |
| Прицелиться | LT | ПКМ |
| ГА! (оглушающая волна) | A | Пробел |
| Перезарядка | X | R |
| Бег | B или L3 | Shift |
| Пауза | Start | Esc |

Зомби идут волнами к сараю с гнездом. Сломают сарай — конец игры. Гуся можно вырубить, через 5 секунд он встаёт. Между волнами выбираешь один апгрейд из трёх. С джойстика работает лёгкий аим-ассист, иначе целиться стиком больно.

Типы зомби: обычные, бегуны (с 2-й волны) и громилы (с 3-й, жирные).

## Гусь: Га-Га-Га (2D)

2D-игра в браузере про ужасного гуся, вдохновлённая Untitled Goose Game. Тыришь вещи у садовника, тащишь их в гнездо, пугаешь его гоготом. Играется с джойстика Xbox 360 (или любого XInput-геймпада) и с клавиатуры.

## Как запустить

Открой `index.html` в Chrome / Edge / Firefox. Сборка и сервер не нужны.

Если хочется через локальный сервер:

```sh
python3 -m http.server 8000
# потом открыть http://localhost:8000
```

## Джойстик

1. Воткни Xbox 360 геймпад (на Windows драйвер встаёт сам).
2. Открой игру и **нажми любую кнопку** на джойстике. Браузер показывает геймпад странице только после нажатия.
3. Внизу слева должно появиться зелёное `🎮 Xbox 360 Controller`.

Вибрация работает в Chrome и Edge. Звук браузер разрешает включить только после клика мышкой или нажатия клавиши, геймпад тут не считается. Поэтому если звука нет, кликни разок по игре.

| Действие | Xbox 360 | Клавиатура |
|---|---|---|
| Ходить | Левый стик / крестовина | WASD / стрелки |
| Бежать | RT или RB | Shift |
| Красться | LT или LB | Ctrl / C |
| ГА! | A | Пробел |
| Схватить / бросить | X или B | E |
| Пауза | Start | Esc |

## Что делать

- Стырить хлеб, ключи, морковку, тапок, радио и шляпу садовника и отнести всё в гнездо.
- Напугать садовника гоготом 3 раза.
- Искупаться в пруду.

Садовник гонится, если видит у тебя в клюве своё добро (жёлтый конус его зрения нарисован на земле). В пруд он не полезет, а в кустах тебя не видно. Гогот рядом с ним пугает его и сбивает шляпу, но и твоя добыча при этом выпадает из клюва.

## Устройство

- `js/input.js` — геймпад (Gamepad API, стандартная и нестандартная раскладка 360-го) + клавиатура
- `js/audio.js` — синтезированные звуки на WebAudio, включая «ГА»
- `js/game.js` — мир, гусь, ИИ садовника, отрисовка на Canvas
